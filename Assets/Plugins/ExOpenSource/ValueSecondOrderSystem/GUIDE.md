# Unity二阶动力学模拟器

## 前言
近日翻了一下老仓库，发现以前写的二阶动力学模拟器，当时痴迷于PCG，对动画很感兴趣。现在索性直接优化一下，封装成插件供大家使用。
本插件参考了著名视频【Giving Personality to Procedural Animations using Math】 https://www.youtube.com/watch?v=KPoeNZZ6H4s


## 概述
本插件提供了基于二阶动力学系统的平滑运动控制，可用于实现相机跟随、物理模拟、UI动画等需要平滑过渡的场景。
插件核心是二阶动力学算法，通过调整频率、阻尼和缩放因子参数，可以创造出从快速响应到缓慢过冲的各种动态效果。

## 核心组件

### 1. SecondOrderDynamicsComponent
挂载在GameObject上的主组件，管理多个动力学实例。

**Inspector面板属性**：
- **instances**：动力学实例列表（可添加多个）
- 点击`+`添加新实例
- **预览**：调试工具
- **绘制值变化示例曲线**：启用/禁用曲线预览
- **所绘制曲线的索引**：选择要预览的实例

### 2. SecondOrderDynamicInstance
动力学实例配置，每个实例可独立控制不同属性。

**配置参数**：

| 参数 | 描述 | 取值范围 |
|------|------|----------|
| 使用替身 | 是否使用外部目标作为输入源 | 布尔值 |
| 替身目标 | 当使用替身时指定的目标Transform | Transform引用 |
| 自动更新参数 | 参数修改时自动更新系统 | 布尔值 |
| 影响属性 | 选择要控制的属性 | Position/Rotation/Scale/Custom |
| 震荡频率 | 控制系统响应速度 | 0.1-10Hz |
| 阻尼 | 控制振荡幅度（0=振荡，1=无超调） | 0-1 |
| 缩放因子 | 控制超调幅度（正值=正向超调） | -10到10 |

**操作按钮**：
- **刷新参数**：手动更新动力学参数（当未启用自动更新时）

## 安装步骤
1. 使用EX开源插件管理器导入插件
2. 确保已安装Odin Inspector插件（用于高级UI功能）
3. 在需要添加动力学效果的游戏对象上：
- 添加组件 → 搜索 `SecondOrderDynamicsComponent`

## 使用教程

### 基础使用
1. 添加`SecondOrderDynamicsComponent`到游戏对象
2. 在`instances`列表中添加新实例
3. 配置实例参数：
```markdown
- 影响属性：Position
- 频率：2.0
- 阻尼：0.7
- 缩放因子：0.5
```
4. 如果使用替身：
- 启用`使用替身`
- 将目标对象拖入`替身目标`字段
5. 如果不使用替身：
- 需要自行调用SetInput(Vector3 value)接口来更新输入值

### 进阶配置
**多属性控制示例**：
1. 添加三个实例分别控制：
- 实例1：Position（跟随目标位置）
- 实例2：Rotation（跟随目标旋转）
- 实例3：Scale（独立控制缩放）

**参数调试技巧**：
- 启用`绘制值变化示例曲线`实时查看响应效果
- 调整频率时：
- 快速响应 → 提高频率(3-5)
- 平滑过渡 → 降低频率(0.5-1.5)
- 消除振荡 → 增加阻尼(接近1)
- 添加动态效果 → 调整缩放因子(正值增加超调)


## 最佳实践
1. **相机跟随**：
- 频率：1.5-2.5
- 阻尼：0.8-0.9
- 缩放因子：0.3-0.6

2. **UI动画**：
- 频率：3-4
- 阻尼：0.95
- 缩放因子：0.1

3. **物理摆动**：
- 频率：0.8-1.2
- 阻尼：0.3-0.5
- 缩放因子：1.5-2.0

## 注意事项
1. 当同时使用多个实例控制同一属性时，最后一个实例会覆盖之前的效果
2. 运行时修改参数后，确保：
- 启用`自动更新参数`或手动点击`刷新参数`
3. 曲线预览仅在Unity编辑器中可用
4. 对于旋转控制，建议使用欧拉角（避免万向节锁问题）

## 故障排除
| 问题现象 | 解决方案 |
|---------|---------|
| 物体剧烈抖动 | 增加阻尼值(0.8-1.0) |
| 响应延迟明显 | 提高频率值(2.0+) |
| 出现不自然超调 | 降低缩放因子(0.1-0.3) |
| 曲线预览不显示 | 检查是否选中有效实例索引 |

## 示例场景
```csharp
// 创建自定义动力学效果
var dynamics = new SecondOrderDynamics();
dynamics.Set(2.0f, 0.8f, 0.5f, transform.position);

void Update() {
// 每帧更新位置
transform.position = dynamics.Update(Time.deltaTime, target.position);
}
```
